# Wall of Voices — social proof surface

Design lives in Figma: **Wall of Voices** — `13hMVjIUc9X1sKOfVHmSc1`.
This repo holds the spec of record, the token source, and the built page.

## The site

`index.html` is the desktop page from Figma node
[`242:6008`](https://www.figma.com/design/13hMVjIUc9X1sKOfVHmSc1/Wall-of-Voices?node-id=242-6008),
built as a static, zero-dependency page. Open it directly:

```sh
open index.html            # or: npx http-server . -p 8080
```

Nothing to install, nothing to build to view it. To regenerate the markup after
editing the content:

```sh
python3 build.py                        # data/posts.json -> index.html
python3 assets/img/_make_placeholders.py   # regenerate the stand-in artwork
```

### Layout

| Path | What it is |
|---|---|
| `index.html` | The built page. Generated — edit `build.py` or `data/posts.json`, not this. |
| `build.py` | Renders `index.html` from `data/posts.json`. Holds the markup for every component. |
| `data/posts.json` | Build-time static record (spec §4): archive posts, homepage-band posts, the featured post, the ledger figures. |
| `tokens/wov.css` | The token set, mirroring the `WOV Tokens` variable collection in Figma. |
| `assets/css/wall-of-voices.css` | All page styling. Every value traces back to a token or a Figma measurement. |
| `assets/js/wall-of-voices.js` | Filter / search / sort, masonry redistribution, counters, entrances, marquee. Progressive — the page is complete without it. |
| `assets/fonts/` | Self-hosted Fraunces, DM Sans, Work Sans, Poppins (OFL). See `assets/fonts/README.md`. |
| `assets/img/` | Stand-in artwork, generated by `_make_placeholders.py`. See **Placeholders** below. |
| `docs/` | The master build spec and the Figma handoff. |

### Sections, in page order

`notice` → `masthead` → `01 Overture` (H1 + hero collage) → `03 Ledger` →
`04 Pull-quote interstitial` → `Explore the Unfiltered Journey!` →

`08 Method note` → `09 CTA` → `6.2 Homepage band` → `footer`.

### What works

- **Archive controls.** Category tabs (proper `role="tablist"`, arrow-key
  navigable), 200 ms-debounced search over name / company / headline, and sort.
  The result count is an `aria-live="polite"` region that stays silent until the
  reader actually narrows the archive, so the page at rest matches the design.
- **Masonry.** At four columns the grid reproduces Figma's exact column
  assignment; once filtered, sorted, or narrowed it repacks shortest-column-first.
  Breakpoints: 4 → 3 (≤1200) → 2 (≤900) → 1 (≤640).
- **Empty state.** Built before the populated one, per spec §10.
- **Motion.** Two durations only (`--wov-dur-micro`, `--wov-dur-enter`), opacity
  + `translateY(8px)` entrances capped at a 6-item stagger, counters that run
  once on first intersection, a marquee that pauses on hover *and* focus-within.
  Under `prefers-reduced-motion` the marquee becomes a static, arrow-controlled
  scroller, counters render final values, and entrances are instant.
- **Accessibility.** Skip link to the archive, visible focus rings everywhere,
  44 px minimum targets on chips / buttons / the card's outbound link, alt text
  on every image, no horizontal scroll at 200 % zoom or at 390 px.

## Fidelity notes and deliberate departures

1. **Static HTML instead of Next.js.** Spec §8 names Next.js App Router,
   statically generated. This repo had no app scaffold, and the design is one
   page, so it is built as static HTML/CSS/JS — statically generated by
   construction, no dependencies, no build step to view. `build.py` plays the
   part of the generator. The markup and CSS port into an App Router page
   unchanged when the archive grows past what a static list can carry and
   virtualization (spec §8) is actually needed.

2. **Placeholder artwork — the Figma bitmaps could not be exported.** The
   network policy on the machine this was built on blocks `figma.com`, so the
   asset URLs returned by the design-context tooling were unreachable, along with
   every stock-photo host. Every photographic element is therefore a generated
   SVG stand-in that holds the **exact geometry the design gives it** — box,
   aspect ratio, crop, radius, opacity, caption — and carries the same subject:
   `assets/img/photo-convocation.svg`, `photo-campus.svg`, `photo-workshop.svg`,
   `photo-immersion.svg`, `photo-portrait-convocation.svg`,
   `photo-graduates-trio.svg`, `photo-profile.svg`, `backdrop-archive.svg`.
   Swap in the cleared photography under the same file names and nothing else
   changes.

3. **Avatars render as initials on `--wov-halo`.** That is state 5 of the
   PostCard in spec §5.1, chosen for the same reason as (2), and it is also the
   state to keep if consent clearance cuts faces (spec §12).

4. **Hero and interstitial collages are rebuilt from live markup.** In Figma
   they are flat rasters. Here they are real cards behind a CSS blur, so they
   stay sharp at any density and reflow instead of stretching.

5. **Categories are inferred.** The Figma filter chips (Convocation, Admission,
   Flying, Alumni, Immersion) carry no per-post category, so each post in
   `data/posts.json` is tagged from its own text. Replace with the real
   `category` field from the repository when the data lands.

6. **`--wov-accent` is still `#E5202E`, a stand-in**, and the page is drawn with
   `--wov-accent-brand: #EE2A3D` as Figma has it. Swap both for the upGrad red
   token from the existing design system. Red still appears in exactly five
   places: logo, one word in the H1, link hover, the active filter chip, the
   primary CTA.

## Before this ships

**Nothing ships until the consent questions in §12 of the spec are answered in
writing.** Every name, post, employer, figure and image on this page is sample
data; the prototype notice at the top of the page says so, and so does the
footer. If avatars or employer names are cut, the PostCard changes shape and
§5.1 has to be redrawn first.
